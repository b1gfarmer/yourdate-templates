# YourDate Seating Planner

A project for visual seating of guests and PDF generation based on a selected template.

## 🚀 Functionality

- Creation of zones, tables and accommodation of guests.
- Dragging guests to their seats.
- Selection of the design template.
- Generate a PDF file with a seating plan.
